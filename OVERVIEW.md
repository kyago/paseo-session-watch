Session watch keeps sessions that wait on you in view on the Paseo desktop window.

When an agent asks for permission, a card appears at the bottom right, above the message box, and stays until it is answered or you open the session from the card. The card shows the session title and the request, with buttons to allow or deny. Questions are answered in the session, which opens when you click the card title. Up to three cards are shown, with a count for the rest. Cmd+Option+Y allows and Cmd+Option+N denies the first request on the top card.

A row in the sidebar header shows how many sessions are running and how many need input. Hovering the row shows the session list beside it, ordered by your most recent message and labelled needs input, failed, running, or finished but unread, with finished sessions folded away. Selecting a session opens it.

Each workspace row in the sidebar shows how many sessions it has, with running and needs-input counts. Hovering those badges lists the workspace's sessions beside the sidebar. Terminal and file tabs are not counted. The badges can be hidden from the sidebar's Show menu.

These cover every connected host that also has this plugin installed, so install it on each daemon you want included. They are hidden on phones and in windows narrower than 768 pixels. Colors follow the active Paseo theme. The interface is in English or Korean, following the app language.
